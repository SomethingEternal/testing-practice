# Проект 5: SQL-запросы на учебной базе Sakila

**Инструмент:** DBeaver, MySQL Server

**Что делала:**
- Установила MySQL Server и DBeaver
- Загрузила учебную базу данных Sakila (16 таблиц, ~46 000 строк данных)
- Написала 10 SQL-запросов разной сложности

**Типы запросов:**
1. Простой SELECT
2. WHERE
3. LIKE
4. COUNT
5. GROUP BY
6. JOIN
7. JOIN + WHERE
8. LEFT JOIN
9. Подзапрос
10. GROUP BY + HAVING

**Результат:** все запросы выполняются успешно, возвращают корректные данные
