# Проект 4: API-тестирование через Postman

**Инструмент:** Postman

**Что делала:**
- Создала коллекцию запросов к JSONPlaceholder API
- Реализовала полный цикл CRUD: GET, POST, PUT, DELETE
- Написала автотесты для проверки статус-кодов и структуры ответа
- Использовала переменные окружения для хранения базового URL

**Запросы в коллекции:**
1. GET All Users — получить список пользователей
2. POST Create User — создать нового пользователя
3. PUT Update User — обновить пользователя
4. DELETE User — удалить пользователя

**Результат:** все запросы выполняются, автотесты пройдены (3/3)
