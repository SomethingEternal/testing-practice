# Проект 6: Автотесты на Playwright (SauceDemo)

**Инструменты:** Python, Playwright, pytest

**Что делала:**
- Написала 5 автотестов для сайта SauceDemo
- Использовала фреймворк pytest и фикстуры (conftest.py)
- Разделила тесты по файлам: вход (test_login.py) и корзина (test_cart.py)

**Тесты:**
1. Успешный вход с валидными данными
2. Вход с неверным паролем (проверка сообщения об ошибке)
3. Вход с пустыми полями (проверка сообщения об ошибке)
4. Добавление товара в корзину
5. Удаление товара из корзины

**Результат:** все 5 тестов проходят успешно

**Как запустить:**
```bash
pip install pytest pytest-playwright
pytest
